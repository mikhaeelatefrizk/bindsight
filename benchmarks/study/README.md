# `benchmarks/study/` — the rediscovery study

Does expression-based discovery resurface clinically validated cell-surface
antigens from real TCGA RNA-seq?

## Read this first

**[`RESULTS.md`](RESULTS.md)** — the whole study, generated from `results.json`.

## What is here

| File | What it is |
|---|---|
| [`RESULTS.md`](RESULTS.md) | The rendered study: denominators, recall cascade, both null models, every pair |
| `results.json` | The artifact everything else is generated from. Every published figure is read from here |
| `figures/` | Two figures, regenerated by the scoring run |
| `run_log.json` | Present after a full `--all` run |

## How it is built

```bash
python benchmarks/run_study.py --all --cpus 2   # fetches cohorts, runs DESeq2 (hours, needs network)
python benchmarks/run_study.py --score-only     # re-scores what is already on disk (fast)
```

Cohorts are cached under `data/gdc_cache/`, which is not committed.

## What makes it interpretable

- **Denominators are pre-registered**, and there are three nested ones because
  they answer three different questions. Merging them would answer none.
- **Every rate carries an interval.** At this panel size the interval, not the
  point estimate, is the finding.
- **Four outcome classes, never merged**: an antigen the reference does not
  contain, one a filter excluded, one the ranking placed low, and one whose
  lookup failed are four different findings about four different parts of the
  system. Separating them found two real pipeline defects.
- **Two null models**, one negative and one positive, both reported.
